# World English Bible audio, read by David Williams (public domain)

Chapter-by-chapter MP3 recordings of the World English Bible (WEB), read by David Williams in 2000-2001 and
released by him into the public domain without restriction. The WEB text is itself public domain (ebible.org).

Source: AudioTreasure, https://www.audiotreasure.com/webindex.htm (also mirrored at
https://publicdomainaudiobibles.com/WEBD.html). This repository only re-hosts the files as release assets so an
app can stream one chapter at a time. 1,189 chapters, 73.4 hours, mono MP3 about 48 kbps.

Files are named `<BOOK>-<chapter>.mp3` with the usual 3-letter book codes (GEN ... REV), for example `MRK-1.mp3`
and `PSA-119.mp3`. `manifest.json` lists the duration in seconds of every chapter.
